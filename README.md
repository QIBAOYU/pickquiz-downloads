## 功能特性

- **多格式导入**：支持 Word（docx/doc）、PDF、TXT 文档导入，也支持拍照 / 相册识图（图片题目 OCR）
- **AI 自动出题**：说句话，AI 按知识点出一套题——知识点不用硬背，刷题练出手感
- **本地 + AI 双通道解析**：本地规则解析离线秒级可用；AI 辅助处理排版复杂、题量大的资料，断网自动回退
- **内置免费 AI**：模型一（智谱 GLM，不限次数）+ 模型二（Agnes，免费不限次、与智谱互相兜底）+ 模型三（千问，每日 2 次），也支持接入 DeepSeek、OpenAI、Claude、Gemini 等自有 Key
- **题型全覆盖**：单选、多选、判断、填空、简答、名词解释、论述、翻译、计算、案例分析、阅读理解、完形填空共 12 种
- **7 种练习模式**：顺序练习、随机练习、背题模式、错题重练、模拟考试、收藏专练、到期复习，进度按模式分别保存
- **题库管理**：置顶、单层分组、长按拖动排序、多选批量删除与合并导出
- **模拟考试**：整卷限时、逐题设分，交卷后统一出成绩
- **即时解析**：答错立刻讲，不攒疑问
- **错题本**：按题库 / 科目汇总，连续答对两次自动移出，支持「待复习 / 高频错题 / 已掌握」分组
- **艾宾浩斯遗忘曲线**：按真实作答数据拟合记忆留存，到期复习自动排程
- **AI 薄弱点诊断**：把真实作答表现交给 AI，生成诊断报告与练习安排
- **学习统计**：掌握度、正确率、近 7 日趋势，分科目 / 分题型 / 分题库多维度统计
- **学习规划**：定方向、找资料，AI 帮你规划学习路线
- **翻译与朗读**：120 种语言翻译，支持拍照识字与朗读
- **题库分享**：分享码、导出题库，方便和朋友交换
- **云端同步**：题库、作答记录、断点进度按账号存云端，换设备自动同步
- **数据备份**：一键导出全量 JSON 备份，可跨账号恢复
- **本地模式**：纯本地运行，断网也能刷题
- **多套主题**：纯白、极简纸感、新拟物、手绘、夜航深色，随手切换
